Welcome to the blog

20 November 2026 · 3 min read

  • meta
  • this site

This is the first post on this site. It exists mostly to prove that the pipeline works: a file goes into posts/, a link shows up on the blog page, and the whole thing gets served straight from GitHub Pages. No database, no build step, no magic.

What this site is

Think of it as a small, quiet home on the internet. There's a page with a few words about me, a place to collect projects, and this blog for the things that don't fit neatly into either. The layout is deliberately boring so the content can be the interesting part.

The whole site is plain HTML, CSS, and a small amount of JavaScript for the theme toggle and project filters. The structure looks like this: 

.
├── index.html          # home page
├── projects/           # project showcase
├── blog/               # post listing
├── posts/              # individual articles
└── assets/
    ├── css/
    ├── js/
    └── favicon.svg

What I'll write about

I expect most posts to fall into one of three buckets:

  • Things I've built — what worked, what didn't, and what I'd change.
  • Things I'm learning — notes from digging into a new language, tool, or idea.
  • Small opinions — about developer experience, testing, and writing software that lasts.

One small rule

Publish the useful version, not the perfect version.

That's the rule I'm trying to follow. If a post helps one person avoid an hour of confusion, it has done its job. Thanks for reading — more will follow.
